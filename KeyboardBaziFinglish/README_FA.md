# کیبورد بازی فینگلیش

پروژه اندروید (Android Studio) برای ساخت APK.

## ساخت
پوشه را در Android Studio باز کنید، Gradle Sync را انجام دهید و از Build > Build APK(s) استفاده کنید.

## نصب
APK را نصب کنید، برنامه را باز کنید، کیبورد را در تنظیمات اندروید فعال کنید و سپس آن را از انتخاب‌گر کیبورد انتخاب کنید.

این نسخه نمونه اولیه است. تبدیل فینگلیش حرف‌به‌حرف است و هنوز تبدیل واژه‌ای دقیق و تجربه کامل مشابه تصاویر را تضمین نمی‌کند. کیبورد فقط در بازی‌هایی کار می‌کند که ورودی استاندارد اندروید را پشتیبانی کنند.
